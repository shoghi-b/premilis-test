# v1 / iteration-1 - Conversion Reporting Replica

## What this iteration shows

This iteration recreates the Omny DSP reporting Conversion screen from the supplied Figma reference.

It includes the Omny application shell, compact left navigation, breadcrumb and filter controls, Conversion tab state, evolution controls, and the grouped performance table.

## Key design idea

Start from an exact visual replica before applying product changes. The table is the main interaction surface and keeps the same grouped column model from Figma:

- Objective
- Efficiency
- Business Results
- Brand Interest
- Delivery Quality
- Control

The table viewport is intentionally narrower than the full table, so users can horizontally scroll to inspect the full column set.
