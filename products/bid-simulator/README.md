# Bid Simulator

Bid Simulator is a design archive for iterations exploring the bid simulator feature.

This feature folder follows the repo workflow:

- Versions live under `v<N>/`.
- Iterations live under `v<N>/iteration-<NN>-<short-desc>/`.
- Each iteration includes `meta.json`, `README.md`, and `CONTEXT.md`.
- Stakeholder visibility is controlled through `meta.json` tags.

## Current Versions

- `v1` — Initial exploration.
